SimpleRightMenu - reorder, hide, and compact the native iOS text selection menu.

Customize the native horizontal iOS text selection menu while keeping its normal presentation and supported app actions.

What it can do:

- Drag and drop to reorder supported menu items in one list, and hide unwanted actions.

- Choose Text, Icon + Text, or compact Icon Only, including distinct Paste and Search icons.

- Add Search Google / Open Link, Google Translate and validated Select All actions.

- On supported iOS 16+ edit menus, Search with AI opens an editable popup containing the selected text and a prompt. Only Send opens Google AI Mode with the complete edited query. Browser routing includes a Safari fallback.

- English and Vietnamese interface; the AI prompt no longer forces the response language.

Automatic menu-show and experimental vertical-menu behavior have been removed. Availability of native actions depends on the current app and text context.

Requires iOS 15 or later. Rootless and RootHide packages are available. Release 1.1.4 has passed source/packaging checks; device behavior of this exact release is not yet confirmed.
